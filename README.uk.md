# 🌍 Природні Мандри (Natural Travels)

Повноцінний веб-застосунок для пошуку, перегляду та створення локацій для відпочинку в Україні.

Платформа дозволяє користувачам знаходити місця, фільтрувати їх за різними параметрами, переглядати реальні відгуки та ділитися власним досвідом подорожей.

---

## 🚀 Основний функціонал

### 🔍 Пошук і відкриття локацій
- Пошук за назвою, типом або регіоном
- Розширена фільтрація (регіон, категорії)
- Сортування (за рейтингом, популярністю, новизною)
- Динамічні параметри в URL

### 🧭 Каталог локацій
- Адаптивна сітка з пагінацією / "Показати ще"
- Динамічне оновлення без перезавантаження сторінки
- Обробка порожнього стану

### 📍 Детальна сторінка локації
- Повна інформація (назва, рейтинг, регіон, тип)
- Оптимізовані зображення
- Перехід на профіль автора
- Блок відгуків

### ⭐ Система відгуків
- Перегляд відгуків користувачів
- Додавання відгуку (тільки для авторизованих)
- Робота через модальні вікна
- Валідація і обробка помилок

### 👤 Авторизація та профіль
- Реєстрація та логін
- Захищені маршрути
- Сторінка профілю користувача
- Умовний рендеринг UI залежно від авторизації

### ➕ Створення та редагування контенту
- Додавання нових локацій
- Редагування існуючих
- Превʼю зображення перед завантаженням
- Валідація форм (Formik + Yup)

### 🎨 UI/UX
- Повністю адаптивний дизайн (mobile-first)
- Hover-ефекти для всіх інтерактивних елементів
- Лоадери для асинхронних запитів
- Toast-повідомлення для зворотного звʼязку

## 🧱 Архітектура

- Server Components використовуються за замовчуванням
- Client Components застосовуються лише при необхідності:
  - форми
  - інтерактивність
  - робота зі стейтом

- Маршрутизація реалізована через App Router
- Захист маршрутів на рівні компонентів
- React Query використовується для роботи з API та кешування
